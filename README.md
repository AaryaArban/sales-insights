# **📊 Sales Analysis using Machine Learning**
This project focuses on performing an in-depth Sales Analysis using Python and key machine learning techniques to uncover trends, forecast future sales, and extract Business Intelligence (BI) insights. By leveraging unsupervised learning via K-Means Clustering and time series forecasting through Facebook Prophet, this analysis offers actionable data-driven decisions for business growth.

**🔍 Project Overview**

Objective:
To analyze historical sales data, identify patterns, cluster similar sales behaviors, and forecast future trends to support strategic decision-making.

Techniques Used:

K-Means Clustering for segmenting sales data and identifying patterns in customer behavior.

Facebook Prophet for time series forecasting and trend detection.

Tools & Technologies:

Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)

Facebook Prophet

Jupyter Notebook

**⚙️ Key Features**

📌 Data Preprocessing: Cleaned and structured raw sales data for further analysis.

📊 Clustering Analysis: Used K-Means to group similar sales patterns based on customer behavior, region, or product categories.

🔮 Forecasting: Applied Facebook Prophet to predict future sales trends and seasonality.

📈 Visualization: Created informative charts for BI reporting (e.g., trend lines, cluster distributions, forecast plots).

📉 Insights: Generated actionable business intelligence such as top-performing regions/products, seasonal trends, and growth opportunities.
